# Папка assets

Сюда добавляйте реальные фотографии школы (здание, уроки, мероприятия и т.д.).

Сейчас все фотографии в проекте — это компонент-заглушка `PhotoPlaceholder`
(см. `src/components/PhotoPlaceholder.jsx`), который рисует стилизованные
SVG-сцены в фирменных цветах школы. Он был использован вместо реальных фото,
чтобы:

1. не создавать вымышленные "реалистичные" фотографии людей;
2. соблюсти требование не показывать лица конкретных учеников/учителей;
3. дать сайту работать сразу после установки, без внешних изображений.

## Как заменить на настоящие фото

1. Положите файлы сюда, например: `assets/building.jpg`, `assets/classroom.jpg`.
2. В нужном компоненте замените `<PhotoPlaceholder scene="..." />` на:
   ```jsx
   import building from '../assets/building.jpg'
   ...
   <img src={building} alt="Здание школы №9" className="w-full h-full object-cover" />
   ```
3. Убедитесь, что на фотографиях не видно лиц людей без согласия на публикацию,
   либо используйте общие планы (класс, здание, мероприятие) без крупных лиц.
