# Сайт школы №9

Официальный сайт общеобразовательной школы №9. React + Vite, Tailwind CSS.

## Быстрый старт

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
  components/   переиспользуемые UI-компоненты (Navbar, Hero, News, Gallery и т.д.)
  pages/        страницы (сейчас одна — HomePage, все разделы на одной странице)
  data/         данные: статистика, новости, мероприятия, галерея, направления
  assets/       место для реальных фотографий (см. assets/README.md)
```

## Как редактировать контент

- **Статистика школы, учителей, учеников, достижения** — `src/data/stats.js`
- **Образовательные направления** — `src/data/programs.js`
- **Новости** — `src/data/news.js`
- **Мероприятия** — `src/data/events.js`
- **Галерея** — `src/data/gallery.js`
- **Контакты** — `src/components/Contact.jsx` (адрес, телефон, email, карта)
- **Логотип и слоган** — `src/components/Logo.jsx`

## Тёмная / светлая тема

Переключатель находится в Navbar (`src/components/ThemeToggle.jsx`).
Выбор темы сохраняется в `localStorage` под ключом `school9-theme`
и применяется мгновенно при следующей загрузке (см. скрипт в `index.html`).

## Приватность

По требованию задания сайт **не содержит** имён, фамилий и личных фото
конкретных учеников или учителей — только обезличенная статистика.
Все "фотографии" — стилизованные SVG-заглушки (см. `src/assets/README.md`)
для замены на реальные снимки школы без крупных лиц.

## Навигация

Сайт одностраничный, навигация между разделами — через якорные ссылки
(`#about`, `#news`, ...), `react-router-dom` не используется.
